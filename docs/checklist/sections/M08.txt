M08 DETAILED REQUIREMENTS

Proposals and questionnaires

P0 core  |  Dependencies: M02, M05, M07

Let clients select clearly priced work and answer useful questions in a durable versioned document flow.

Inspect proposal and questionnaire behavior

[ ] M08-001  Inspect existing proposal, agreement and intake editors, template use, persisted answers and shared-document routes; verify whether proposal and invoice components genuinely share data or merely resemble each other.

[ ] M08-002  Complete an existing test proposal and questionnaire end to end; compare each requirement below, skip working equivalents and extend only missing selection, persistence or client-action behavior.

Document list and draft fields

[ ] M08-003  Provide Documents with Type filters All, Proposals, Contracts and Questionnaires; show Title, Client, Project, Lifecycle status, Shared date and Updated, with access-controlled search.

[ ] M08-004  Provide New proposal and New questionnaire with required Title, Client and Project; offer From template or Blank, default From template when a compatible ready template exists.

[ ] M08-005  Provide optional Introductory text and Expiration date; default no expiration, show the chosen business timezone and reject an expiration before the planned send time.

[ ] M08-006  Expose sections Content, Services, Questions and Sharing as appropriate to the document type; keep the underlying document identifier and client/project links stable while editing.

[ ] M08-007  Provide Draft, Sent, Viewed, Partially signed, Signed, Declined, Expired and Voided lifecycle filters only where applicable; derive signature states from M09 events instead of selection confirmation.

[ ] M08-008  Offer Save draft, Preview, Share, Duplicate and Void actions according to lifecycle; Duplicate creates a new draft without copying answers, approvals, delivery history or signatures.

Service selection and calculations

[ ] M08-009  Add services from M07 or enter a custom line with required Name, Quantity, Unit, Unit price and Currency; require one document currency and display line amounts using its precision.

[ ] M08-010  Provide selection modes Required item, Optional item and Choose one group, default Required item; require a labeled group with at least two choices before using Choose one group.

[ ] M08-018  Give each question a stable key, required label, optional help text and Required toggle default off; preserve the label and validation rules attached to already submitted document versions.

[ ] M08-019  Allow conditional display with Always or Show when a prior select/checkbox Equals a specified answer; prevent circular references and exclude hidden questions from required validation.

[ ] M08-020  Autosave changed answers after a two-second idle period and show Saving, Saved with time or Not saved; never display Saved until the server acknowledges the current revision.

[ ] M08-021  Provide Save and finish later and Submit answers; submitting validates every visible required question and scrolls to an accessible error summary while preserving all entered answers.

[ ] M08-022  Keep partially completed answers accessible only to the intended participant and authorized business users; scope resume links to the document and never use sequential public identifiers as authorization.
