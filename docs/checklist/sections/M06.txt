M06 DETAILED REQUIREMENTS

Client portal

P0 core  |  Dependencies: M02, M05

Give each invited client a clear secure place to review shared work and complete the next action.

Inspect existing client access

[ ] M06-001  Inspect current agreement links, portal previews, login paths, participant records and storage permissions; verify which paths are genuinely client-facing before building a separate portal.

[ ] M06-002  Open every existing client view as guest, invited client and owner of another business; inspect all requirements below, retain verified equivalents and extend only missing access or presentation behavior.

Portal settings and invitation

[ ] M06-003  Place a Client portal panel in Project settings with Enable portal, Participants, Visible sections and Preview as client; default Enable portal off until the owner explicitly shares it.

[ ] M06-004  Provide Add participant with required Name and validated Email plus optional Role label; match the intended contact explicitly and do not grant access through an email string alone.

[ ] M06-005  Provide participant access options View shared work and View and complete assigned actions, default View shared work; grant document signing separately to each named signer.

[ ] M06-006  Offer Invite, Copy invitation link, Resend invitation and Revoke access; display Pending, Active or Revoked based on actual invite and access state rather than a successful button click.

[ ] M06-007  Use an existing verified email sign-in-link or account flow; display link expiry before sending, default new sign-in links to 24 hours and invalidate them after successful exchange.

[ ] M06-008  After expired or used sign-in links, show Request a new link without revealing whether another person's email is registered; rate-limit requests and avoid duplicate invitations.

[ ] M06-009  Keep existing authenticated business owners in the correct client context after accepting an invitation; show a clear Return to my business action without redirecting away from the invited project.

Portal navigation and shared content

[ ] M06-010  Provide portal sections Overview, Tasks, Documents, Invoices and payments, Meetings, Messages and Files; hide disabled or unavailable sections and retain equivalent working labels.

Failure states and authorization

[ ] M06-028  Enforce participant and business boundaries on every document, task, file and payment request; a copied URL alone must not grant access beyond its intended scoped authorization.
