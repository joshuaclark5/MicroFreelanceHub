M11 DETAILED REQUIREMENTS

Invoice editor and document controls

P0 core  |  Dependencies: M02, M05, M07

Create accurate, versioned invoices from existing project data and preserve the exact document that each client receives.

Inspect existing invoices before changing them

[ ] M11-001  Inspect each existing invoice route, editor, schema, calculation and PDF against this module; record working evidence and skip matching behavior, extend partial behavior, and preserve existing invoice IDs and project links.

[ ] M11-002  Compare the current internal invoice workspace with the agreement payment flow using synthetic records; identify the authoritative invoice and ledger IDs before connecting them, and prevent a second invoice for an existing obligation.

[ ] M11-003  Place the invoice list under Invoices with Create invoice, Search and Filters; show Number, Client, Project, Issue date, Due date, Currency, Total, Applied payments, Balance and derived Status columns.

[ ] M11-004  Provide invoice filters Client, Project, Currency, Issue date range, Due date range and Status choices All, Draft, Open, Partially paid, Paid, Overdue, Void and Uncollectible; apply M14/M16 predicates and offer Clear filters.

[ ] M11-005  Show No invoices yet with Create invoice before any records exist and No matching invoices with Clear filters for an empty search; distinguish loading from load failure and provide Retry without discarding current filters.

Invoice fields and line items

[ ] M11-006  Make Create invoice require Client and Currency; make Project optional and restricted to that client's projects, prefill business currency without silently replacing a project's existing currency, and offer Create client through M02.

[ ] M11-007  Provide Number mode Automatic or Custom, default Automatic and require a number only for Custom; require Issue date, default today in business timezone, and Due rule On receipt, Net 7, Net 14, Net 30 or Custom date.

[ ] M11-008  Provide optional Purchase order/reference, Invoice title, Client message, Payment terms and Internal note fields; label Internal note as business-only and exclude it from client screens, emails and exported documents.

[ ] M11-009  Assign unique tenant-scoped invoice numbers on publication using the existing sequence; allow an authorized unused custom number, show conflicts inline, and never reuse a voided number or silently renumber a published invoice.

[ ] M11-010  Offer a searchable ISO Currency dropdown containing supported business currencies; show the code beside amounts, enforce that currency's minor-unit precision, and lock currency after publication or any associated payment event.

Discounts taxes charges and rounding

[ ] M11-014  Provide Invoice discount choices None, Percentage and Fixed amount; default to None, require a value for the latter choices, limit percentages to 0–100, and reject discounts exceeding the eligible item subtotal.

[ ] M11-015  Give each line a Tax dropdown containing No tax and active saved rates, plus Create tax rate for Owner/Admin; require rate name and percentage, allow four decimal places, and preserve historical rate snapshots.

[ ] M11-016  Provide Tax calculation choices Exclusive and Inclusive, defaulting to the business setting; show a plain-language preview of whether entered prices include tax, and require review before changing a draft's existing calculation mode.

[ ] M11-017  Provide Service charge choices None, Fixed amount and Percentage with a required label and optional saved tax rate; calculate percentage charges on discounted pre-tax items, apply the invoice tax mode, and treat fixed charges as gross in Inclusive mode or net in Exclusive mode.

[ ] M11-018  Calculate each line extension from quantity multiplied by unit price using decimal arithmetic; round monetary results half-up to currency minor units, never use binary floating-point totals, and persist calculation inputs with the published version.

[ ] M11-019  Apply invoice discounts before tax; allocate their minor units proportionally across eligible line extensions using largest remainders and stable line-ID tie-breaking, so allocated discounts exactly equal the displayed invoice discount.

[ ] M11-020  For Exclusive tax, round each discounted line's tax separately; for Inclusive tax, derive rounded net as discounted gross divided by one plus rate and define tax as gross minus net, without compound taxes.
